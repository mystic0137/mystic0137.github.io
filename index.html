Agentic Knowledge Graph Construction
complete
Same 5-agent pipeline built twice — ADK vs. LangGraph, benchmarked head-to-head
Multi-agent system that constructs Neo4j knowledge graphs from mixed structured (CSV) and unstructured (Markdown / plain-text) data, modeling a furniture supply chain — products, assemblies, parts, suppliers, and customer reviews — so a bad review can be traced back to the responsible part and supplier for root-cause analysis. Five specialized agents handle user-intent, file proposal, NER/schema induction, fact extraction, and a propose → critique → retry schema-refinement loop.

Reimplemented the identical pipeline in both Google ADK and LangChain/LangGraph over a framework-agnostic core (prompts, tools, state, Neo4j backend shared once), then proved equivalence — both emit identical work (19 LLM calls / 15 tool calls / 2,622 tokens) pinned by cross-framework tests. A deterministic offline mock mode isolates pure orchestration overhead, benchmarked across cold-start, wall time, CPU, memory, and tokens — quantifying ADK's ~3× heavier cold start against near-parity steady-state.
